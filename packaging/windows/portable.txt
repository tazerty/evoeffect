EvoEffect portable mode

While this file sits next to evoeffect.exe, EvoEffect keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the EvoEffectData folder beside it instead of
%APPDATA%\EvoEffect. Copy the whole folder to move EvoEffect with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\EvoEffect unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\EvoEffect) instead.
If EvoEffectData can't be written (for example on a read-only drive), EvoEffect logs a
warning and uses %APPDATA%\EvoEffect instead.
